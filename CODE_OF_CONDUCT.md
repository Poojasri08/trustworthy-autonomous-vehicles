# Code of Conduct

## Our Commitment

We are committed to creating an open, respectful, and collaborative environment for everyone contributing to this project.

## Expected Behavior

Contributors should:

- Communicate respectfully and professionally.
- Provide constructive feedback.
- Respect different viewpoints and experiences.
- Share accurate and responsible security information.
- Follow ethical research practices.

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment or discrimination.
- Personal attacks or offensive comments.
- Sharing misleading security claims.
- Publishing vulnerabilities irresponsibly.
- Plagiarism or unauthorized copying of work.

## Security Research

Security researchers are encouraged to report vulnerabilities responsibly and provide information that helps improve the project.

## Enforcement

Project maintainers may remove contributions or restrict participation if this code of conduct is violated.

## Thank You

Every contributor helps improve the security and trustworthiness of autonomous vehicle systems.
