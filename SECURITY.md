# Security Policy

## Overview

Security is a critical part of building trustworthy autonomous vehicle systems. We welcome responsible reports that help improve the security and reliability of this project.

## Supported Versions

| Version | Supported |
|---------|-----------|
| Main branch | ✅ |
| Older versions | ❌ |

## Reporting a Security Issue

If you discover a potential security vulnerability:

- Do not publicly disclose the issue immediately.
- Provide a clear description of the vulnerability.
- Include steps to reproduce the issue if possible.
- Explain the potential impact.
- Suggest possible mitigation approaches.

## Security Review Process

Reported issues will be reviewed to:

1. Validate the reported vulnerability.
2. Assess the potential risk.
3. Develop appropriate mitigation strategies.
4. Document the resolution.

## Responsible Disclosure

Security researchers and contributors are encouraged to report issues responsibly and allow time for investigation and fixes before public disclosure.

## Scope

Security reports may include:

- AI model vulnerabilities
- Data integrity issues
- Authentication weaknesses
- Software vulnerabilities
- Vehicle communication security concerns

Thank you for helping improve trustworthy autonomous vehicle security.
